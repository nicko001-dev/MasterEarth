# Internationalization

English source text is the key used by the shared catalog in
`src/i18n/index.js`. User-visible text should use `t()`, `tn()`, or `msg()`, or
an appropriate `data-i18n*` attribute in UI markup.

```js
t('Saved {name}', { name });
tn(count, '{count} camera', '{count} cameras');
```

`t()` supports named placeholders. `tn()` selects a plural form using the
active locale. `msg()` marks a string stored in data so it can be translated
later. UI markup can mark text with `data-i18n` and attributes with
`data-i18n-title`, `data-i18n-aria-label`, or `data-i18n-placeholder`.
`data-i18n-runtime` is for text that code sets through `t()`.

The shipped catalogs live in `src/i18n/locales/`. Run `npm run i18n` to verify
catalog coverage and find UI text that is not marked. Keep intentional
exceptions explicit with a nearby `// i18n-ignore` comment explaining why; do
not use the exception to hide a missing shared-catalog entry.

When adding or changing translated strings, keep all locale catalogs in sync.
The checker reports missing translations and unmarked UI text; it does not
generate translations.
